# Shared tiled algorithm diagnostic

The [execution-design diagnosis](../results/2026-10-13-execution-gap.md) locates
two large differences from JAX: scalar-F32 training operations and inefficient
cooperative algorithms. A same-algorithm CUDA translation was similarly slow.
This follow-up tests whether the existing aligned, vector-loaded, prefetched
matrix algorithm can serve explicit F16/BF16 storage as well as legacy F32.
It is an isolated diagnostic, not a production promotion or Atari allocation.

## Fixed intervention

- Base Meganeura `056562b`, with the previously qualified latest Blade
  `fe5f5b5` / Naga `a4b4183`. No change to production pins.
- Generalize the existing aligned cooperative generator, not another BF16-only
  kernel. Typed full tiles use 64×64 output, K32 staging, register prefetch and
  128 threads. Retain the checked kernel for incomplete tiles. Existing legacy
  F32 geometry remains unchanged. No tuning sweep.
- Preserve operand/output precision, F32 accumulation, K partition boundaries,
  addend order and BF16 rounding. Padding and cooperative output staging must
  respect element width and shared-memory limits.
- Preserve model, batch, replay, optimizer and learner graphs. No convolution,
  grouped derivative or host-scheduling change in this intervention.

## Validation and measurement

Validate generated F32/F16/BF16 shaders on CPU, then bounded guarded GPU checks:
existing independent dense/gradient/convolution tests plus aligned typed cases
covering transpose, addends, split reductions and reduced output. Existing exact
F64 gates stay fixed. Failure stops the affected allocation for source review.

After numerical qualification, run one ordinary matched full-update pair for
RGB12M/B8/BF16 and CDP12M/B32/mixed: 16 warmup + 256 measured updates. Compare all
272 reports, first targets, and initial/first/final tensors with the unchanged
latest-compiler control. No expected exactness is silently relaxed. Each process
is bounded to 300 seconds. One matched pair of fixed four-shape diagnostics
(16 warmup + 128 recorded calls/shape) compares outputs and F64 probes;
only the wide and transposed complete tiles should change implementation.

The fixed microbenchmark is evidence about those kernels, not projected whole
agent savings. Failure to close a substantial part of this bucket redirects work
to the already identified grouped/backward precision coverage, not a tile sweep.
No sum of independent timings is a promise of JAX parity.
