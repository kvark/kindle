# Experiment protocols and results

Start with the [current working instructions](../../AGENTS.md),
[roadmap](../kindle_single_life_dreamer_plan.md), and
[machine handover](../handover.md). [PR31](https://github.com/kvark/kindle/pull/31)
is the live status dashboard. These sources identify the selected allocation;
a dated protocol's historical next steps do not authorize restarting its work.

This directory contains experiment declarations. [Result reports](../results/)
retain outcomes, limitations, failures and links to external artifacts.
Completed learners, evaluations, collectors and diagnostics remain closed.
Consult the relevant protocol and current state before a separately justified
new experiment; an observer timeout alone does not establish that work stopped.

Current AMD training uses Auto precision and the exact runtime/runner declared
for each experiment. Native learning remains on Meganeura and Blade. Backend
optimization, upstream porting and JAX parity are parked.

Older material remains on
[archive/phase2-before-cleanup-20261025](https://github.com/kvark/kindle/tree/archive/phase2-before-cleanup-20261025/docs).
Its host pins, incident state, timings and unstarted queues are historical.
The Breakout context64/F16/Auto comparisons are completed; their reports remain
in the roadmap and handover, with the original host failures preserved.
