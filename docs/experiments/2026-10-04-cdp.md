# Evaluate small Dreamer-CDP against RGB Dreamer

Authorized by the active user goal, **evaluate the CDP path**. This takes
priority over the unstarted posterior-Tiny ablation; retain its implementation
and stopped qualification, without launching it. Learned RGB remains the
qualified 2D default until this comparison supplies evidence for a change.

## Question and fixed method

Can a jointly learned small CNN with continuous deterministic prediction retain
useful control information at lower whole-agent cost than pixel reconstruction?
This tests CDP's complete objective/optimization recipe, not cosine distance or
encoder learning rate in isolation. It is not a new Tiny representation matrix.

Reference: [Dreamer-CDP v2](https://arxiv.org/html/2603.07083v2), released
[implementation](https://github.com/fmi-basel/Dreamer-CDP/tree/a851fa3e3d70b624b094ee1810ad4bb602346092).
CDP is JEPA-style learning within Dreamer, not a pretrained LeVJEPA encoder.
Its published Crafter/XL result is not evidence for our small Atari model, and
the paper does not establish measured wall-clock savings. The released detached
RGB visualization decoder does not train its world representation; omit that
decoder entirely here. No new GPU kernel, EMA encoder or video pretraining.

Both arms use the qualified Dreamer CNN, categorical RSSM and actor/critic.
Control reconstructs RGB64 with weight1 and world/behavior rate4e-5. Candidate
predicts the next CNN embedding from the deterministic recurrent state, before
the target frame enters the posterior: one hidden layer at embedding width,
RMSNorm/SiLU, linear output. Targets are stop-gradient; the encoder still learns
through posterior/KL, reward, replay-value and temporal source paths.
CDP uses mean cosine distance with squared-norm floor1e-8, weight500,
encoder rate6e-6, complete RSSM/posterior/predictor rate4e-4 and other rates4e-5.
As in the reference, CDP includes episode-start targets. The former frozen-feature
MSE/reset-mask path is unchanged. No posterior auxiliary head or actor gradients
are added (`ac_grads=false`). Raw pixels remain in replay and are re-encoded.

## Qualification before learning

- CPU config/serialization/refusal and graph-shape tests; ordinary tests,
  formatting and strict Clippy. Preserve the first cosine scalar-shape failure.
- Independent F64 cosine values and raw gradients, including zero/small norms,
  and detached target verification on the native GPU.
- Four real native full learner updates per arm, compared to the pinned
  upstream RGB/CDP modules: values, raw gradients, common-gradient LaProp with
  all rate groups, moments and slow-critic EMA. The reference only adapts naming,
  fixed draws/unrolling and omission of the detached visualization decoder.
  Inspect shared initial tensors; decoder/predictor differences are expected.
- Native pixel replay, encoder movement, independent stream resets, exact
  checkpoint/optimizer restore and read-only forecasts for CDP and RGB.
- One production N8/B8/T16 smoke per arm, 1,024 actual actions; excluded from
  learning evidence. Finite reports, native device and sampled memory gates.
  No repeated timing micro-campaign: learner and full-agent costs come from the
  matched production runs, with construction reported separately.

**1009/2017/3019**, **200,000 actual executed actions and49,939 updates per run**.

sticky.25, repeat4, no reset no-ops, 100000-frame artificial cutoff; no action,
reward or exploration aid. AGC.3, warmup1000; all other settings are the current
qualified small recipe. Pair order: RGB/CDP1009, CDP/RGB2017, RGB/CDP3019.
Existing RGB runs are historical context, not controls for changed backend pins.

Report all score-vs-actions/time curves, final last50 completed-episode means
(or all if fewer), unfinished tails and paired learner-seed bootstrap intervals.
One final checkpoint per run; no validation/test-selected world checkpoint.
Retain failures, interrupted work and every completed episode. No best-seed
selection, automatic restart or expansion if results are weak. Each learning
job has a60-minute deadline; a finite but slower candidate is still evidence.

## Frozen world/control diagnostics

Restore each final model without learning. Reuse the fixed random-trajectory
split seeds9101/9109/9127 (train),10103/10111 (validation),11113/11117/11131 (test),
4096 actions each. These are additional diagnostic interactions, not training.
Every model must receive identical actions, rewards and terminal traces. Record
CNN embeddings and full posterior; sample causal h1/h15 forecasts every16
actions with paired unrelated-action draws. Keep forecasts within episodes.

Fit the existing native GPU position readout (hidden128/B64,2048 updates,
seed20261003, training-only normalization, validation-only selection) on current
CNN/posterior and h1/h15 full-prior states, four heads/model. RAM coordinates
are diagnostic labels only. Compare both coordinates, training/generalization
gap, persistence and unrelated actions on identical origins. For CDP also
report embedding cosine prediction versus persistence and constant train-mean
controls, representation spread and effective rank. Reward forecasts use zero
and unrelated-action controls with event counts. No imagined-RGB claim for CDP.
Fitted readouts and transferred heads are not interchangeable evidence.

Audit unchanged saved model/optimizer tensors, zero learner updates and exact
h1 deterministic-prior/next-posterior alignment. Retain compressed arrays and
all split/head selection results. Frozen random-action probes are not frozen
policy competence. Judge learning benefit primarily on return versus actions
and wall time; a smaller prediction loss alone is insufficient.
