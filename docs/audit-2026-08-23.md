# Project audit and remediation — 2026-08-23

Scope: core Rust agent, native environments/examples, Python bindings and
harnesses, Atari/ARC preprocessing, dependencies, CI, documentation, and
outcome benchmarks. This is the current status report; the July audit is
retained as the pre-remediation record.

## Outcome

The project is materially smaller and its core task-reward path is now
demonstrably functional. Dead credit-assignment machinery and obsolete
configuration were removed, environment transitions now carry complete RL
semantics, visual Atari observations no longer collapse to zero tokens, and
dynamic action masks remain aligned through delayed PPO/SIL training.

Intrinsic-only CartPole now closes the original M3 outcome gate. The retained
recipe ranks the negative homeostatic deviation signal per step; episode-return
GRPO and SIL are disabled because accumulating a negative-only penalty makes
short failures appear better than long balancing episodes. `extrinsic_alpha=0`
prevents both task reward and explicit success events from reaching the agent,
and now also suppresses the harness's return-triggered learning-rate change.
After exactly 50k training decisions, frozen greedy evaluation returns
500/500/215 across seeds 42–44, versus 22.11/22.74/22.42 for matched random
actions. The primitive is generic, but CartPole still declares pole angle,
target zero, and tolerance as its homeostatic state; this is intrinsic control,
not autonomous goal discovery.

Cross-game competence now has behavioral gates rather than only a stability
trace. One 32/64 task-conditioned policy trains on eight CartPole and eight Taxi
lanes concurrently. Orthogonal task codes enter the policy encoder, GRPO groups
only same-task lanes, action masks retain each game's legal action set, and SIL
keeps admission baselines per task and samples active tasks evenly. Three fresh
agents pass both frozen sampled-policy gates: CartPole returns
485.40/482.37/402.43 and Taxi completion 92.3%/95.6%/90.3%. A current 16/32
seed-42 ablation reaches only 78.7% Taxi completion, and greedy wide-model Taxi
reaches 87.1%, so this proves simultaneous sampled-policy competence—not
arbitrary cross-game generalization or deterministic navigation on every
state.

The same agent also passes a three-seed sequential CartPole→Taxi→CartPole gate.
Before switching, CartPole returns 488.18/493.80/486.31; Taxi then reaches
93.9%/92.8%/93.3%; after Taxi training, frozen CartPole still returns
253.50/500.00/229.98. This required two correctness changes beyond concurrent
training: SIL capacity now preserves inactive tasks while updates sample only
tasks active in current lanes, and the first eight task ids receive orthogonal
codes instead of dense vectors whose trainable projection columns all changed
on every task. Reverse Taxi→CartPole retention passes seeds 42 and 44, but seed
43 retains Taxi at 89.6%, so order-independent continual learning remains open.

Taxi, MountainCar, and Acrobot now have reliable three-seed completion gates. Taxi's
unmasked extrinsic-only run
remained near the random regime; per-step shaping and legal-action masking
exposed partial learning, while corrected event-filtered SIL retained complete
successful trajectories despite negative step costs. Mean returns remain
negative, so efficient/near-optimal routing is not yet established. MountainCar
needs temporally coherent repeated actions to discover its first success, then
event SIL retains the negative-return trajectory; a large replay buffer is
important for preserving diverse momentum phases. It completes reliably but
does not yet reach reward-optimal speed.
Acrobot similarly uses repeat-four exploration to collect 50 successful
trajectories before switching to repeat two for finer control. Its completion
rate reaches 93–97.5%, though returns show that successful swing-up is still
slow.
Pendulum exposed a separate continuous-control defect: scaling a regression
target by advantage is not equivalent to weighting its squared error. Kindle
now feeds raw continuous actions and explicitly multiplies each per-row
fixed-variance Gaussian loss by the signed advantage; both latent and
end-to-end continuous graphs share that objective. The loss also masks the 17
padded universal outputs for Pendulum so only its one live action contributes;
the unmasked heads dominated the earlier loss and made the reported reward-only
improvement invalid. With the corrected mask, reward-only learning does not
beat random. Harness-local
DAgger executes Kindle's policy while labeling each visited state with a
deterministic swing-up controller, then freezes learning for greedy evaluation.
It reaches the expert regime on two of three seeds; the third reaches -497.27,
so Pendulum is not claimed as a reliable autonomous or multi-seed solve.
Breakout is also not solved; this is evidence that Kindle improves a pixel
policy over random. Pong did not improve at 200k steps (-20.43 learner versus
-20.31 random), nor in the new 128k-decision matched ablations, so
positive/negative sparse-event credit remains open. A connected-component
controller using only the same 84x84 frame stack navigates substantially better
at frame skip 1 (-11.50 versus -20.03 random). A purpose-built direct
cross-entropy path now distills the controller's structured motion token into
Kindle: it reaches 100% accuracy on 768 balanced training rows and 98.8% on 256
held-out rows, then a fresh zero-update checkpoint reload scores -12.60 over
five games/120k decisions. This closes controller retention but is supervised
imitation, not autonomous reward learning or Pong completion. Starting from
that checkpoint changes the outcome of online credit assignment: 120k raw-
reward decisions across 24 lanes, with the trained motion encoder frozen,
reduce the three-seed evaluation point deficit from 368 to 237 (35.6%) and
improve every seed. Aggregate completed-game return moves from -14.06 to
-13.43, while positive-point fraction rises from 27.2% to 32.9%. A separate
zero-update reload reproduces the result; the encoder's
maximum change is zero and the policy-head L1 change is 12.426. This is genuine
extrinsic-reward improvement after supervised initialization, but it does not
show learning from pixels/rewards alone. A separate path starts with random
weights and supplies a class-balanced scalar reward for agreeing with the
motion token's ball-intercept direction. It uses no executed controller actions
or supervised-training API, and raw Pong points remain active. Its restored
best checkpoint scores -13.20/-13.60/-10.75 across three fresh 120k-decision
seeds, with at least 98.7% active tracking per seed; a separate zero-update
reload reproduces the aggregate -12.64 return and +246/-503 points. This proves
from-random optimization of a dense task-specific reward. It does not prove
autonomous reward discovery or sparse-score-only learning because the reward
function itself encodes the desired tracking action.

## Removed or simplified

- Removed the broken L0/L1 credit subsystem, its graph sessions, diagnostics,
  buffers, no-op configuration, and the stale Taxi credit probe.
- Removed invalid planner-RND and other ignored compatibility knobs rather
  than continuing to expose settings that did nothing.
- Removed the attempted Pong demonstration warm-start API/CLI after both
  stochastic and greedy held-out policies stayed at or below the random point
  ratio. The negative result is retained in `docs/failed_experiments.md`.
- Renamed persistence APIs to `save_weights`/`load_weights`, accurately
  describing their current weights-only behavior.
- Replaced repeated native reward/homeostatic/boundary plumbing with
  `Agent::observe_step_results` and migrated every native example/test.
- Pinned the Meganeura and Blade revisions used by both Rust manifests.

## Correctness fixes with broad impact

- GRPO now compares lanes within the same task; episode GRPO uses the full
  policy return, including extrinsic reward. SIL sampling is deterministic.
- Event-filtered SIL ranks event episodes against event episodes instead of
  letting failures depress its admission baseline. It admits the first sparse
  success and applies a minimum imitation advantage to its complete trajectory,
  fixing the loss of early actions on tasks with negative step costs. This
  raises Taxi completion from the old 60% single-seed/40-episode reading to
  90–95% across three seeds and a 200-episode final window.
- SIL dispatch is now independent of whether the live on-policy batch happened
  to have non-zero advantage. Previously default `n_step=1` agents could fill
  replay forever without executing it, while multi-epoch PPO could execute SIL
  once per epoch. It now runs once at the configured policy cadence; a GPU
  canary covers the default path.
- SIL admission baselines are keyed by task id. Replay capacity water-fills
  across represented tasks, including inactive ones, while updates
  round-robin only across ids active in current lanes. Previously a +500
  CartPole baseline rejected every successful negative-return Taxi episode,
  long trajectories dominated the global FIFO, and stale task labels blocked
  post-switch adaptation. Single-task FIFO behavior is unchanged.
- Agents may opt into orthogonal codes for common task ids so training one task
  updates one column of the trainable task projection rather than every future
  task's adapter bias; the native multitask gate enables it. Overflow ids use
  normalized deterministic hashes. The default historical dense codes remain
  checkpoint-compatible. Regression tests cover baseline isolation,
  task-balanced sampling, inactive-task capacity retention, single-task FIFO,
  and both task-code modes.
- Continuing tasks may retain a bounded backward SIL window immediately at a
  positive event without fabricating an environment boundary or cutting the
  world-model trajectory. This remains opt-in: its Pong ablation was negative.
- Native transitions carry an explicit positive task-event bit separate from
  scalar reward, termination, and truncation. This credits MountainCar's
  negative-reward goal without misclassifying CartPole failure as success.
- RND reward is invariant to lane order.
- Atari obtains a 64-dimensional visual history/spatial token instead of a
  zero vector; Python regression coverage enforces it.
- The Atari harness now defaults to the spatial Nature-DQN encoder instead of
  the global-average-pooling CNN that its own implementation documents as
  unsuitable for spatial control. Its bare reward mode explicitly disables
  intrinsic weights, and `extrinsic_grpo` provides one named learning recipe.
- Atari preprocessing exposes frame skip and sticky-action probability rather
  than baking them into the environment factory. Controller-only random and
  Pong modes avoid constructing/training an irrelevant GPU agent, report
  signed point-event counts, and support executable return/episode gates. The
  visual Pong controller projects ball motion through wall reflections.
- Pong controller labels and learner inputs now share one 64-value structured
  motion token, preventing feature drift between collection and inference. A
  reproducible harness balances unique states across the four controller
  actions, applies direct masked cross-entropy, persists its held-out split,
  and evaluates only through a newly loaded zero-update agent. The frozen
  policy passes the -15 return gate at -12.60; this path is explicitly
  supervised.
- A second Pong harness continues only the distilled policy head with raw
  signed environment rewards and same-task GRPO. Freezing `policy_encoder.*`
  prevents the catastrophic forgetting observed when the full policy was
  updated. Its gate compares freshly loaded source and fine-tuned checkpoints
  over the same three seeds, requires every seed's point deficit to improve,
  requires every seed's positive-point fraction to improve and at least 75% of
  events to remain observable, checks at least 20% aggregate deficit
  improvement, and verifies the encoder remained byte-stable at the parameter
  level.
- A from-random Pong harness converts agreement with the model-visible
  ball-intercept direction into class-balanced signed scalar reward. Redundant
  actions remain masked, the optimizer receives no supervised labels, and the
  raw environment points stay enabled. Entropy recovery is deliberately off:
  the matched entropy-floor ablation erased the balanced reward signal. A
  fixed, class-balanced token set selects and restores the best checkpoint so
  late policy collapse cannot be reported as learning.
- The native harness accepts an ordered, unique seed list and applies every
  configured outcome gate independently to each fresh agent. Its CartPole
  return-triggered learning-rate schedule is now conditional on a non-zero
  extrinsic channel, preventing an external score metric from steering an
  intrinsic-only run. Training and frozen-evaluation decision counts are
  reported separately.
- An optional per-frame median foreground residual increases Pong latent
  diversity (mean cross-lane latent std 0.0239 to 0.0477 at 32k decisions) but
  did not improve return, so it remains an off-by-default representation
  ablation rather than a preset.
- Agents and Python bindings expose deterministic policy-mode action selection
  for honest evaluation. It is not used during exploration; on the rejected
  Pong imitation run it scored worse than stochastic evaluation, preventing a
  misleading claim based only on lower entropy.
- Continuous policy gradients now use an explicit per-row advantage input.
  The previous implementation fed `advantage * action` as the MSE target,
  which made zero advantage train the mean toward zero and negative advantage
  train toward a sign-flipped action. Padded universal action heads are now
  excluded from the Gaussian loss. End-to-end continuous policies are
  supported as well; unsupported continuous PPO/KL-PPO/SIL combinations fail
  at construction instead of reaching incompatible graph inputs later.
- The native outcome harness has matched random, expert, Kindle, and DAgger
  modes plus a frozen greedy evaluation phase for continuous Pendulum. DAgger
  is deliberately harness-local and freezes the unrelated world model; it is
  not a restored generic demonstration API or evidence of reward-only mastery.
- Gymnasium vector harnesses use same-step autoreset, train on `final_obs`, and
  stage the reset observation only for the next action. The old next-step mode
  silently discarded an action after every completed episode.
- Encoder reconstruction is enabled by default, encoder changes are canaried,
  and world-model dynamics loss is reported separately from reconstruction.
- Native `StepResult` carries reward, positive task event, termination, and
  truncation while preserving the terminal observation/homeostatic state across
  auto-reset.
- Native CartPole, MountainCar, Acrobot, Taxi, and Pendulum implement explicit
  episode limits and task rewards; GridWorld exposes its food reward.
- Environments can expose a legal-action mask. Transitions/SIL samples retain
  the collection-time mask, delayed clipped PPO replays it, and KL-PPO now
  masks both policy and KL distributions. A GPU canary alternates masks across
  delayed rollout rows.
- Plain discrete policy graphs now mask padded/unavailable actions too;
  entropy recovery smooths only across valid actions. Entropy coefficients
  apply to mean policy entropy as documented rather than being silently
  divided by `MAX_ACTION_DIM`.
- Python Gym exposes reproducible return gates and uses correct zero-intrinsic
  defaults for an extrinsic benchmark.
- ARC action indices now retain one fixed `GameAction` meaning across changing
  availability sets; random policies and macros sample valid values rather
  than list positions. Single- and multi-game harnesses expose event/max-level
  gates, and the joint harness has a seeded no-training baseline mode.
- ARC summaries no longer mistake cumulative `levels_completed` retained
  across reset for repeated episode competence. They report lifetime max and
  per-attempt gains. This invalidated the old “100% L1” CD82 claim.
- Coordinate REINFORCE accepts an active-lane mask, excludes rewards from
  non-coordinate actions, and is wired into the joint trainer. Previously the
  joint trainer used random coordinates exclusively, while the single-game
  trainer reinforced sampled coordinates even on ordinary discrete actions.
  Its reward baseline is now per lane, and ARC explicitly credits positive
  level deltas instead of letting dense intrinsic surprise steer clicks.
- Parameterized actions no longer alias in learned dynamics. The policy keeps
  an 18-way discrete label, while the world model, normal replay, surprise
  replay, and k-step training receive a 20-value action token with normalized
  `(x, y)`. All ARC harnesses stage the coordinates actually executed, and
  one-shot staging prevents stale coordinates from leaking to later actions. A
  GPU canary trains opposite parameter values to reach different states and
  verifies that the learned predictions select the correct branch.
- Shooting MPC searches parameterized action tuples, preserves selected
  coordinates through `act()`, and rejects queued actions made illegal by a
  newer dynamic mask. `planner_action_repeat` now actually repeats its action
  and coordinate instead of resampling. Parameterized spaces route away from
  the discrete-only MCTS tree. A GPU canary verifies that change-scored
  shooting selects the learned state-changing coordinate.
- The optional ARC object extractor no longer requires SciPy for a 64×64
  connected-component pass. It infers the modal background instead of assuming
  color zero, returns a representative cell that belongs to concave components,
  and ranks pieces nested in panels before their containers. On FT09 this made
  all eight one-step state-changing cells fit in the 11 object slots; the prior
  area order placed them at ranks 21–33. Object slots are stable semantic
  actions rather than freely parameterized planner aliases.
- The GRPO harness's missing-ARC error path no longer crashes from a
  function-local `sys` shadow. ARC dependency markers preserve Kindle's Python
  3.9 core support while declaring the ARC packages' Python 3.12 floor.
- A separate local ARC object-search harness turns all visible components into
  parameterized candidates, removes duplicate outcomes, detects commuting
  involutions, and searches action combinations against external level reward.
  Non-commutative graphs regenerate proposals per state, because an action or
  coordinate that is a no-op at the root can become useful later. State and
  transition caps bound clone cost, and rejected engine branches no longer
  abort a multi-game run. The curated L1 gate passes 8/8 games in 246 expanded
  states; the broader complex-action corpus reaches 8/19. FT09 reaches L2, and
  a larger VC33 probe reaches L3 in 33 total solution actions and 1,169 total
  expansions. It intentionally requires cloneable local simulators.
- Successful ARC search paths can be exported as pre-action visual tokens,
  availability masks, stable action identities, and normalized coordinates.
  Hybrid object/pixel tokens remove aliases found in the pure object encoding.
  A narrow supervised categorical update trains positive masked CE directly;
  the CPU coordinate head now uses the raw token plus a fixed task embedding,
  avoiding a redundant GPU encode while preventing cross-game click
  interference. Compatible corpora merge with duplicate removal and conflict
  detection. The joint 53-sample checkpoint reloads into batch-1 agents and
  reaches L1 on 8/8 games plus L2 on FT09/VC33 (100% action-label accuracy,
  coordinate MSE 0.001792) when learned clicks are projected onto visible
  objects and stable object-space motion is extrapolated. Nearest-object
  projection by itself still chooses the wrong SU15 target. Extrapolation now
  yields to a raw prediction more than five pixels away, preventing a valid
  repeated-coordinate sequence from suppressing a later deliberate jump.
- VC33 L3 demonstrations expose the limit of the current coordinate
  abstraction. Per-task-balanced fitting preserves the existing L1/L2 gate
  but still replays only to L2, and a VC33-only head fails too. A temporary
  64-way policy that classified ranked objects also failed to overfit the 76
  unique rows (best 86.8% after 100,000 updates), because the 64-value token
  represents only a small prefix of a variable object set. The universal head
  remains 18-way; ranked object labels stay in search exports as diagnostics.
- Search exports now retain 12 normalized features for every current object.
  A persisted two-layer pointer scores that variable set after Kindle chooses
  the stable complex-action identity. It fits all 67 complex labels in the
  76-row corpus and, from a separate zero-update checkpoint reload, reaches L1
  on all eight games, FT09 L2, and VC33 L3. The largest demonstrated set has 65
  candidates; no clone, coordinate projection, motion heuristic, or widened
  universal policy head is used during evaluation.
- GPU tests are a hard Linux CI gate rather than `continue-on-error`.

## Remaining priorities

1. **Atari completion and autonomous ARC learning.** Breakout has a progress
   gate and ARC now has executable outcome gates plus retained search
   imitation, but Atari completion and an online ARC gate that beats a
   calibrated random baseline remain open. Pong remains random-level when
   learning uses sparse signed points alone at these budgets; standard Atari
   agents normally need millions of decisions, so short-run knob sweeps should
   not be treated as completion evidence. Direct supervised cross-entropy
   retains the frame-skip-1 pixel controller, and a subsequent controller-free
   extrinsic phase improves all three evaluation seeds by 35.6% aggregate point
   deficit. A separate random-initialized policy passes when given dense
   tracking-consistency reward, but that reward encodes the task-specific
   control decision. This closes a shaped-reward navigation gate, not
   autonomous reward discovery, sparse-score-only learning, or completion. The
   historical ARC recipes and online coordinate learner also underperform
   random at matched short budgets.
2. **Intrinsic-only breadth and autonomous goals.** Intrinsic-only CartPole is
   closed across three frozen seeds, but its environment supplies the
   homeostatic variable and desired target. Comparable gates on visual games
   and task discovery without a hand-declared health target remain open.
3. **Native game efficiency and continuous control.** Taxi, MountainCar, and
   Acrobot now complete at least 90% of episodes on three seeds, but their route
   efficiency/control speed remain open. Pendulum's corrected reward-only
   policy does not beat random; online expert correction solves only two of
   three seeds, so stable autonomous continuous control remains open.
4. **Cross-game breadth, transfer, and retention.** One shared policy now
   passes simultaneous CartPole and Taxi gates and a sequential
   CartPole→Taxi→CartPole curriculum on three seeds. Reverse-order retention
   passes only two of three seeds. Adding the remaining native games,
   eliminating order sensitivity, and measuring positive transfer rather than
   coexistence remain open.
5. **Representation/planning coherence.** End-to-end policy mode owns a
   policy encoder separate from the world-model latent and is explicitly
   incompatible with policy-guided world-model planning. A shared or bridged
   representation is needed before those features compose cleanly.
6. **True resumability.** Checkpoints save parameters, not optimizer moments,
   replay/SIL buffers, visit counts, task state, RNG state, or environment
   state. Long Atari/ARC training cannot yet resume exactly.
7. **ARC task-progress objective.** Learned dynamics, replay, shooting, and
   execution now distinguish ARC clicks, but generic novelty/change scoring did
   not beat random on the first three-seed FT09 probe. Object-centric candidates
   improve cold-start coverage (3/3 seeds reached L1 versus 2/3 for uniform
   coordinates) but still do not reach L2. Clone-backed object search proves
   that structured action abstraction plus external reward can reach L2 on
   FT09 and through L3 on VC33, but its deeper graphs remain combinatorial. Coordinate
   and action distillation now retains all eight demonstrated L1 paths, FT09
   L2, and VC33 L3 in one joint checkpoint without clone access. A variable-set
   candidate pointer replaces failed coordinate regression and fixed-rank
   classification while the universal action head remains 18-way. It has not
   retained unseen levels. The remaining gap
   is generalizing beyond demonstrated states and learning a task-progress/value
   heuristic that reduces or replaces simulator-backed search.
8. **Python hygiene.** CI now format- and Clippy-checks the Python binding's
   Rust crate, which sits outside the root Cargo workspace. The older Python
   experiment corpus still needs a deliberately reviewed Ruff cleanup: broad
   exception recovery and long-lived trace files require policy decisions,
   while bulk formatter churn should be separated from behavioral changes.

These are the next architectural/outcome risks. Adding more reward modules or
planner knobs before closing them would increase surface area without proving
additional game competence.
