# Bounded F32 tuning: not adopted

Meganeura's existing private-scratch tuner gives **185.90 → 183.49 ms/update
(1.013×)** in one short synthetic pair. This is not a convincing whole-learner
gain. Experimental hooks were removed; production keeps the measured
[fused/grouped learner](2026-09-27-fused-learner.md).

[Self-contained configuration, timings, losses and trial decisions](2026-09-27-f32-tuning.json).
Both arms use the same executable, seed 0, 12M/B16/T64/full-BPTT/M16/H15/R256,
F32 prediction-only, 36 updates with four timing warmups. No frontend,
pretraining or action/reward aid. All **241 tensors / 146 optimizer moments
and every non-timing report match exactly**. No game or learning-curve
comparison was run; fixed order and short timing remain limitations.

Each of five sessions permits 16 classes, 64 MiB scratch and a 10-second soft
limit. The search takes 13.47 seconds, excluded from update timings. Its trial
decisions include 33 faster candidates, 385 retained baselines, 11 scratch-limit
refusals and 11 invalid-output rejections. The latter report a Tile32 reference
or cross-variant mismatch on private test inputs, not the live learner. These
rejections remain in the result; no cause or general tuning reliability is
established. This bounded search is not exhaustive and does not justify adoption.

Both direct native guards pass and reap their children on RTX 5080 / 580.178.04;
sampled Vulkan estimated headroom stays above 12.55 GB. No separate NVML polling,
host recovery or successor job. The optional patch, executable and raw reports
remain in [local evidence](../../runs/f32-tuning-20260927.6utTAH/).
